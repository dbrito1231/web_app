## Command-syntax check (changed or added commands)

All of the following were checked against the CLI v2 reference and are valid as written for PS 5.1:
- **Waiters:** `ec2 wait volume-available` / `instance-terminated` / `nat-gateway-deleted`; `elbv2 wait target-in-service` / `load-balancers-deleted`; `rds wait db-instance-deleted`; `elasticache wait cache-cluster-deleted`; `eks wait nodegroup-deleted` / `fargate-profile-deleted` / `cluster-deleted`; `ecs wait services-inactive` / `tasks-stopped`; `dynamodb wait table-not-exists`; `route53 wait resource-record-sets-changed --id`.
- **Deletes and actions:**
  - EC2: `ec2 describe-nat-gateways --filter` (singular).
  - WAF: `wafv2 disassociate-web-acl --resource-arn`; `wafv2 get-web-acl --query LockToken`.
  - Athena: `athena delete-work-group --recursive-delete-option`.
  - Step Functions: `stepfunctions list-executions --status-filter RUNNING`.
  - Cognito: `cognito-idp list-user-pools --max-results 60` (the parameter is required).
  - ECS: `ecs list-tasks --desired-status RUNNING`; `ecs delete-service --force`.
  - Secrets Manager: `secretsmanager delete-secret --force-delete-without-recovery`.
  - Glue: `glue list-crawlers`.
- **JMESPath:** `TableNames[?@=='…']`; `ends_with(TopicArn, ':workbook-ul10')`.
- **PowerShell:** the `$( )` interpolation.

Teardown dependency order is correct in every changed lab. Specific checks:
- The NACL is moved back to the default NACL before the custom NACL is deleted.
- Route tables are disassociated before they are deleted.
- The EIP is released before the IGW is detached.
- The MT SG is deleted before the instance SG.
- The copy DB is deleted before the source, and the snapshot and subnet group only after the waits.
- WAF is removed before the ALB.
- Node groups and Fargate profiles are removed before the cluster, and roles after the cluster.

Protection against deleting anything outside the lab:
- Default NACL lookups are scoped by `vpc-id`.
- UL lookups use exact names.

Exceptions are AWS-R3-007 (UL-16 `$VpcId`) and AWS-R3-011 (UL-18 SG found by group-name only).

## Regression hunt

- **`ResizeObserver` header variable** (`Header.tsx:20-31`)
  - **Leaks:** none. The observer disconnects on unmount. The Header lives in `WorkbookShell`, which stays mounted across tab routes (`/:tabSlug`), so it mounts once. The inline `--header-h` is not removed on unmount, which is harmless.
  - **SSR:** not applicable (Vite SPA). `document` is only touched inside the effect.
  - **First paint:** before the effect runs, the CSS uses the 176px fallback. `setVar()` runs synchronously in the effect, before any fetch resolves, so the first scroll always sees the measured value. This is confirmed by the variable reading 64/115/176px right after navigation.
  - **Live resize:** I could not verify it in the background tab. There `requestAnimationFrame` never fires (`visibilityState: hidden`), so the RO callbacks do not run, and after a 375 → 1280 resize the variable stayed `176px` against an actual height of 64. This is a test-harness limitation, not a code defect. A stale variable larger than the real header is harmless (a larger margin).
- **`useSearchParams` loops and double fetches**
  - Exam card clicks: exactly one `/api/questions/<id>` per click, with no repeats.
  - Start-here mount: 2× `/api/lessons/<id>` and 2× `/api/content/summary`. That is StrictMode's dev double-effect, and the same happens on a fresh load.
  - Start-here picker change: **3× lesson and 3× summary** (FS-R4-002).
  - No infinite loops were seen.
- **Keyboard:** Tab order is heading → Study link → the rest (fixed). After the Study link is activated, focus falls to `BODY` (FS-R4-001).
- **Console:** no errors.
